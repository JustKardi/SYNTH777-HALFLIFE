# SYNTH777-HALFLIFE


## Description

SYNTH-777 is a DIY cyberpunk themed synthesizer made for the Hack Club Half Life week 3. It features 8 rotary encoders, 4 potentiometers, 4 buttons, 4 sliders, and a 4.3 inch touchscreen. It also comes with 42 capacative pads to represent piano keys, spanning two octaves. As for output, it uses a 3.5mm audio jack. It powers through USB-C, and steps power from the input voltage to 5V. This 5V is then separated into 3.3V, 2.5V, 1.8V, 1.1V, and VDDA (3.3V). As for internal processing, the brain is an ESP32-P4, connected to two MPR121QR2s to control all 24 keys. The board is designed to be printed on a 6-Layer PCB.
